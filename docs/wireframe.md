# Wireframe

배포된 사이트를 기준으로 만든 뼈대 와이어프레임입니다. 실제 화면(1440×900, 390×844)에서 요소마다 위치와 크기를 재서 옮겼습니다.

- Figma: https://www.figma.com/design/Gq8TmNVt7qPHGKGSDSeBB7/Random-book
- Live: https://random-book-five.vercel.app

## 파일 구성

| 페이지 | 내용 |
| --- | --- |
| `wireframe` | 위 줄 1440 화면 11개, 아래 줄 390 화면 11개 |
| `parts` | 와이어프레임 박스 부품 `box` |

## 그리드

사이트 CSS 값을 그대로 옮겼습니다. 모든 화면에 같은 값을 적용했고, 레이아웃 그리드는 켜고 끌 수 있습니다.

| | 1440 | 390 |
| --- | --- | --- |
| 컬럼 | 12 | 4 |
| 여백 | 251 (종이 187 + 안쪽 64) | 46 (종이 24 + 안쪽 22) |
| 거터 | 22 | 14 |
| 칸 너비 | 58 | 64 |
| 레이어 종이 너비 | 1066 (`min(1120px, 74vw)`) | 342 (`100vw - 48px`) |
| 상단 메뉴 높이 | 76 | 60 |

- 종이 가장자리는 보조선으로 표시했습니다 (1440: 187 / 1253, 390: 24 / 366).
- 빨간 숫자는 각 화면의 `grid` 그룹 안에 해당 위치에만 적었습니다.

## 화면 목록

사이트에 나오는 순서입니다.

| 화면 | 내용 |
| --- | --- |
| `intro` | 바탕에 깔린 브랜드 글자, 스크롤 안내, 이미지 칸, 진행 막대 |
| `story` | 왼쪽 이야기, 가운데 이미지, 오른쪽 오프라인 안내와 3단계 |
| `picks` | 책 4권 (1440: 4칸, 390: 2×2) |
| `menu` | 햄버거 메뉴 |
| `main` | 레이어: cover, land, theme, credit, row |
| `wrap` | 레이어: head, copy, steps (색 안내 포함) |
| `reserve` | 레이어: intro, form, notice |
| `bring` | 레이어: spines, intro, qa, rules |
| `visit` | 레이어 끝, 흰 선, 큰 브랜드 글자, 푸터 |
| `ticket` | 방문 티켓 (지도, 평면도, 정보) |
| `guide` | 포스트잇 안내 (1440: 레이어 옆, 390: 아래 목록) |

## 표현 규칙

- 회색 바탕 위 흰 면이 레이어 종이입니다. 뒤에 겹친 레이어는 흐린 흰 면으로 실제 자리에 깔았습니다.
- 내용은 이름표가 달린 회색 박스로만 표시했습니다. 색, 둥근 모서리, 그림자는 쓰지 않았습니다.
- 레이어 화면의 `layer-tab`은 안내를 닫은 뒤 남는 포스트잇 탭 자리입니다. 실제 사이트처럼 모든 레이어보다 뒤에 있습니다.
- 이름은 모두 케밥케이스입니다.
